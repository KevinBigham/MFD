# MFD Play Guide

Run a football franchise through the season, offseason, and the years that follow. Your main jobs are managing players, staff, contracts, game plans, and the decisions that shape your dynasty.

[Open MFD](https://kevinbigham.github.io/MFD/)

## Start a dynasty

1. Choose **New Dynasty**, select a franchise, and read the difficulty guide before choosing a difficulty.
2. Choose your setup path:

   | Path | What it does |
   | --- | --- |
   | **Instant** | Opens a ready-to-play franchise without the full setup process. |
   | **Guided** | Keeps the important choices and preloads recommendations. |
   | **Full GM** | Lets you make every Day 1 staffing, identity, and roster decision. |

3. Select **Start Instant**, **Start Guided**, or **Start Full GM**. Complete any setup choices shown.
4. Begin with **Monday Briefing**. Follow the current decisions and upcoming opponent information.

When you return, **Continue Latest Autosave** resumes the latest available autosave in that browser. Use the save tools below when moving to another browser or computer.

## Play one week at a time

1. Read Monday Briefing and the Action Center. Handle required decisions first; recommended and optional choices help you plan the week.
2. Review your roster, depth chart, injuries, contracts, and available cap space before making changes.
3. Set your game plan and weekly preparation. Read each action's cost and consequence before confirming it.
4. Use **Week Advance** when you are ready. If an action blocks advance, complete the action shown.
5. Review Game Day, the result, injuries, and any new decisions. Then begin the next week.

The season proceeds through the championship and into offseason decisions. Use the screen's current phase and next action to stay oriented. Chip can provide weekly and screen-specific guidance when enabled.

## Save and move your dynasty

Open **Save/Load** to reach **Dynasty Cartridge**.

| Action | Use it for |
| --- | --- |
| **Create Save Slot** | A manual checkpoint stored in this browser. |
| **Download Combined Backup** | A portable file containing the current dynasty cartridge plus the browser's supported dynasty-history archives. Use this before switching browsers or computers. |
| **Upload Combined Backup** | Restoring a combined backup. Read its import preview before confirming. |
| **Advanced: Download .mfd** / **Advanced: Upload .mfd** | Current-save-only recovery. This older format does not include the separate dynasty-history archives. |

Combined Backup includes supported Hall of Fame, scrapbook, GM career, roster continuity, Rookie of the Year, and rivalry history. Local save slots and autosaves stay in browser storage; a downloaded file gives you a copy outside that browser.

Before an import, download a backup of the dynasty already open. Check the team, season, included history, and replacement warnings in the preview. **Confirm Combined Import** applies the import; cancel if it is not the backup you intended. A combined archive can include history from more than one dynasty in that browser.

Watch List pins are browser-local convenience state and do not travel with `.mfd` or Combined Backup. Re-pin those players after moving browsers. Portable exports also omit some heavy broadcast/replay detail; keep an original backup if you need to compare or recover an earlier save.

## Adjust the experience

Use **Settings** for audio controls and the available gameplay/display preferences. Adjust Chip's controls if you want less guidance. The **About** screen shows the app and save versions; **FAQ** answers common launch questions.

## Report a problem

[Open a repository issue](https://github.com/KevinBigham/MFD/issues) with the screen or route, what you tried, what happened, browser, and versions shown in About. Include any error context the app provides. Keep an unchanged copy of your backup while investigating a save problem.
