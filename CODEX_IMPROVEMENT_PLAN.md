## Operating Principles

- Preserve deterministic simulation: seed plus centralized RNG must still reproduce outcomes.
- Preserve save compatibility: persistent `GameState` changes require type, schema, migration, seed/default, fixture, and old-save tests.
- Prefer wiring existing engine systems into clearer UI before inventing new systems.
- Make decisions legible: show immediate impact, season impact, future risk, confidence/uncertainty, and why it matters.
- Ship vertical slices. Each slice should include data/engine if needed, store/action wiring, UI, tests, and guide updates.
